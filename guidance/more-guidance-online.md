# More guidance online

This `guidance/` folder is **not exhaustive.** It's a snapshot of the
material Kyle has written up so far. He keeps adding new guidance docs
to the upstream starter-pack repo as new AIOS-building territory gets
explored.

**Upstream repo:**
<https://github.com/kyledunne/aios-starter-pack-project>

## For agents

If you're tackling a setup task that isn't covered by anything in this
local copy of `guidance/`, check the upstream repo's `guidance/`
folder for newer material before improvising. The local copy may
simply be older than the latest.

Two quick ways to check:

- **Browse the folder on GitHub:**
  <https://github.com/kyledunne/aios-starter-pack-project/tree/main/guidance>
- **Pull the latest copy down** into a scratch directory (don't
  overwrite the local copy unless the user wants that):

  ```
  git clone https://github.com/kyledunne/aios-starter-pack-project.git /tmp/aios-starter-pack-latest
  ls /tmp/aios-starter-pack-latest/guidance
  ```

If a relevant new doc exists upstream, read it inline rather than
duplicating it into the user's AIOS. The starter pack is reference
material; it doesn't belong copied wholesale into anyone's repo.
